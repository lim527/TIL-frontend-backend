# Algorithm Practice

프로그래머스 기반 Java/Python 알고리즘 연습 기록

## 파일 이름 규칙

`날짜_문제이름.확장자` 형식으로 저장한다.

예시:
- `algorithm/java/250727_짝수와홀수.java`
- `algorithm/python/250727_짝수와홀수.py`

같은 문제는 java, python 두 언어 폴더에 각각 같은 파일명으로 저장해서,
나중에 언어별 차이를 비교하기 쉽게 한다.
